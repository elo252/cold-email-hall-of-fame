# Cold Email Hall of Fame — Claude skill

A Claude skill that drafts, critiques and plans cold emails using patterns from 43 documented cold emails that got replies from people like Bill Gates, Mark Cuban, Marc Benioff, Elon Musk and Sundar Pichai.

## Install
- **Claude apps:** Settings → Capabilities → Skills → upload this folder as a .zip.
- **Claude Code:** copy this folder to `~/.claude/skills/cold-email-hall-of-fame/`.

## What's inside
- `SKILL.md` — the workflow, playbooks by goal, critique checklist and a 43-entry casebook.
- `references/emails.json` — the full database: every entry with tactics, evidence level and source links.
- `references/emails.csv` — the same data for spreadsheets.

## Try it
- "Help me cold email Jason Lemkin about my SaaS startup. We're at $40K MRR."
- "Critique this cold email to a hiring manager at Stripe: ..."
- "I got rejected from an accelerator. Should I reply, and what do I say?"

## About the data
Every email is paraphrased from public sources and linked; original texts are not reproduced. Each entry has an evidence label (primary, multi-source, single-source, self-reported, gated). Compiled October 2026. Inspired by Siddharth Haldar's Cold Email Hall of Fame newsletter (cold-email-hall-of-fame.beehiiv.com).
